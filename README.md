# India-CPI-Inflation-Analysis

## 1. Project Overview
This project focuses on analysing India`s Customer Price Index (CPI) data using Microsoft Excel. The workbook contains the original dataset and 
separate worksheets for question-based analysis.

## 2. Project Statement 
The objective of this project is to analyse India`s CPI data, understand inflation trends examine category-wise contributions, and identify
meaningful patterns in the available data.
The analysis aims to answer specific questions using Excel calculations, data analysis techniques, and visualisation.

## 3. Project Objectives
- Analyse India`s CPI dataset.
- Examine category-wise contributions to the CPI basket.
- Calculate and analyse year-over-year inflation trends.
- Identity periods of higher inflation.
- Investigate relationships between variables.
- Interpret analytical results using Microsoft Excel.
